In `src/lib/motion.js`, refactor `useScrollFx`:

1. **Remove Mobile Suppression**:
   - Remove the `!mobile` condition from `if (cards.length && !mobile)`. Change to `if (cards.length)`.
   - Retain `mobile` or calculate responsive tiers:
     ```javascript
     const isPhone = window.innerWidth <= 767
     const isTablet = window.innerWidth > 767 && window.innerWidth <= 1023
     ```

2. **Adaptive Scroll Travel Distance**:
   - Replace the hardcoded `vh * 0.62` with responsive distance:
     ```javascript
     const scrollDistance = isPhone ? vh * 0.48 : isTablet ? vh * 0.54 : vh * 0.62
     const raw = Math.min(1, Math.max(0, window.scrollY / scrollDistance))
     ```

3. **Responsive Card Fit & Rotation Dampening**:
   - On phone screens, scale down spread width and dampen rotation slightly so the 5 cards fan out gracefully without colliding or breaching screen margins:
     ```javascript
     const fit = isPhone
       ? Math.min(0.55, (window.innerWidth - 32) / 720)
       : Math.min(1.0, (window.innerWidth - 48) / 1120)
     const rotFactor = isPhone ? 0.65 : isTablet ? 0.85 : 1.0
     ```

4. **Dynamic Origin Band & Height Solving**:
   - Compute band boundaries accounting for mobile viewport heights:
     ```javascript
     const copyBottom = copy ? copy.getBoundingClientRect().bottom - hTop : H * 0.42
     const bandTop = copyBottom + (isPhone ? 16 : 24)
     const bandBottom = Math.min(H, vh) - (isPhone ? 28 : 52)
     const band = Math.max(160, bandBottom - bandTop - cyUp - cyDown)
     s = Math.min(s, band / (up + down))
     origin.style.top = `${(bandBottom - s * down - cyDown).toFixed(1)}px`
     ```

5. **Horizontal Translation Bounding**:
   - Compute translation bound preventing card overflow:
     ```javascript
     const bound = Math.max(80, window.innerWidth / 2 - (isPhone ? 28 : 120))
     for (const c of cards) {
       const x = Math.max(-bound, Math.min(bound, c.fx * p * fit))
       const y = c.fy * p * s
       const r = c.fr * p * rotFactor
       c.el.style.transform = `translate(${x.toFixed(1)}px,${y.toFixed(1)}px) rotate(${r.toFixed(2)}deg) scale(${(cs * s).toFixed(3)})`
     }
     ```

6. **Synchronized Title Veils and Hero Copy Fade**:
   - Title veil timing:
     ```javascript
     const FADE_IN = isPhone ? 0.20 : 0.25
     const opened = Math.max(0, Math.min(1, (p - P_REST) / (1 - P_REST)))
     const veil = Math.max(0, Math.min(1, (opened - FADE_IN) / (1 - FADE_IN)))
     for (const el of titles) el.style.opacity = veil.toFixed(3)
     ```
   - Hero copy drift:
     ```javascript
     const copyDrift = isPhone ? 24 : 40
     const copyFadeMultiplier = isPhone ? 1.6 : 1.4
     document.querySelectorAll('[data-hero-copy]').forEach((el) => {
       el.style.opacity = String(Math.max(0, 1 - raw * copyFadeMultiplier))
       el.style.transform = `translateY(${(-raw * copyDrift).toFixed(1)}px)`
     })
     ```
