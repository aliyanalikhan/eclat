<action>
1. In `src/components/MagazinePreview.jsx`:
   - Add touch swipe detection state (`touchStartX = useRef(null)`, `touchStartY = useRef(null)`):
     - `onTouchStart`: record initial `clientX` and `clientY`.
     - `onTouchEnd`: calculate `deltaX = e.changedTouches[0].clientX - touchStartX.current` and `deltaY = e.changedTouches[0].clientY - touchStartY.current`.
     - If `Math.abs(deltaX) > 40 && Math.abs(deltaX) > Math.abs(deltaY) * 1.5`:
       - If `deltaX < 0 && index < pages.length - 1`: advance page (`setIndex(i => i + 1)`, set direction `forward`).
       - If `deltaX > 0 && index > 0`: turn back page (`setIndex(i => i - 1)`, set direction `backward`).
   - Add directional animation tracking:
     - Keep track of `slideDir` (`'forward'` | `'backward'` | `null`) and apply CSS class `is-sliding-forward` or `is-sliding-backward` to the image on turn, resetting after transition or on index change.
   - Add adjacent page preloading:
     - Add `useEffect` on `[index, pages]` that prefetches `pages[index + 1]`, `pages[index + 2]`, and `pages[index - 1]` using `const img = new Image(); img.src = url;`.
   - Ensure the image container has `touch-action: pan-y;` or `touch-action: none;` on the frame so vertical swiping doesn't cause browser page stutter.

2. In `src/styles/eclat.css`:
   - Define directional slide keyframes:
     ```css

       }
     }

     @keyframes flipSlideInLeft {
       from {

       }
       to {

         transform: translateX(0) scale(1);
       }
     }

     .magazine-preview__img.is-sliding-forward {
       animation: flipSlideInRight 0.2s cubic-bezier(0.16, 1, 0.3, 1) both;

     @media (prefers-reduced-motion: reduce) {
       .magazine-preview__img.is-sliding-forward,
       .magazine-preview__img.is-sliding-backward {

     }
     ```
