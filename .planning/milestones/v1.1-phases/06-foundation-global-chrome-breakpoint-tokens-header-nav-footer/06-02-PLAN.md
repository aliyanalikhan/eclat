## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser ↔ index.html viewport meta | `viewport-fit=cover` is a static, build-time HTML attribute; no request or user input influences it |
| Browser ↔ eclat.css `env(safe-area-inset-*)` | Inset values come from the OS/device hardware report, not user-controllable content; used only for padding, never for content injection |
| Header.jsx auth-slot JS/state ↔ eclat.css new selectors | This plan adds zero JS/markup changes to Header.jsx; the new `.nav .auth-trigger`/`.auth-menu__item`/`.nav>.btn` CSS only re-sizes already-existing, already-hardened auth-slot markup |
