## Requirements Shipped & Validated

### Breakpoint Architecture & Fluid Sizing (RESP)
- [x] **RESP-01**: Unified multi-tier breakpoint system across CSS and JS (Phone <768px, Tablet 768–1024px, Desktop 1024–1440px, Ultrawide >1440px) replacing fragmented ad-hoc pixel values.
- [x] **RESP-02**: Fluid typographic and spacing tokens using `clamp()` so headlines, body copy, and container paddings scale smoothly across all viewports.
- [x] **RESP-03**: Zero unintended horizontal overflow guarantee site-wide across all routes and viewport widths (from 320px up to 4K+).

### Hero Animation & Multi-Device Adaptation (HERO)
- [x] **HERO-01**: Preserve existing rAF scroll-based fan animation mechanics while adapting geometry and card scaling smoothly across screen tiers.
- [x] **HERO-02**: Responsive fan bounding & fit logic in `useScrollFx`: dynamically calculate card spread, translation bounds, and scale so cards remain visible and unclipped on all viewports.
- [x] **HERO-03**: Preserve hero scroll reveal / fade transitions and side card title unveil timing matching desktop feel across all capable screen widths.
- [x] **HERO-04**: Maintain strict adherence to `prefers-reduced-motion: reduce` with single settled pass and zero animation jumps.

### Content Pages & Multi-Device Grids (GRID)
- [x] **GRID-01**: Archive, Editions, Books, and Writings listing grids reflow cleanly across all 4 breakpoint tiers (1-col mobile, 2-col tablet, 3-col desktop, 4-col ultrawide).
- [x] **GRID-02**: Cultural Icons, Videos, and book drag-scroll strips support native smooth touch swipe on touch devices and pointer drag on desktop.
- [x] **GRID-03**: Editorial detail pages (Edition, Writings, Book detail) maintain optimal reading line-lengths and proportional media display across all screens.

### Overlays & Chrome Adaptation (OVERLAY)
- [x] **OVERLAY-01**: Magazine preview flipbook modal scales dynamically to viewport aspect ratio and height on mobile, tablet, and desktop without clipping.
- [x] **OVERLAY-02**: Lightbox zoom overlay maintains image proportions, touch-action, and prevents background rubber-band scrolling on mobile and desktop.
- [x] **OVERLAY-03**: Global header navigation and footer adapt seamlessly across mobile drawer and desktop bar with safe-area inset support.
