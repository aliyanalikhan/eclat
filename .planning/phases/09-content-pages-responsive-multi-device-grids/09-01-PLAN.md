In `src/styles/eclat.css`:

1. **Standardize Base Desktop Grids (`1024px+`)**:
   - For `.grid-covers` (Archive & Editions):
     ```css
     .grid-covers {
       display: grid;
       grid-template-columns: repeat(auto-fill, minmax(230px, 1fr));
       gap: 36px 24px;
     }
     ```
   - For `.books-grid` (Books):
     ```css
     .books-grid {
       display: grid;
       grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
       gap: 44px 32px;
     }
     ```
   - For `.writings` and `.writing`:
     Ensure desktop tabular/card rows align smoothly with `--shell`.

2. **Tablet Reflow (`@media (max-width: 1023px)`)**:
   - Add/update rules for tablet:
     ```css
     .grid-covers {
       grid-template-columns: repeat(auto-fill, minmax(180px, 1fr));
       gap: 28px 20px;
     }
     .books-grid {
       grid-template-columns: repeat(2, minmax(0, 1fr));
       gap: 36px 24px;
     }
     ```

3. **Phone Reflow (`@media (max-width: 767px)`)**:
   - Update `.grid-covers` to 2-column compact thumbnail layout:
     ```css
     .grid-covers {
       grid-template-columns: repeat(2, minmax(0, 1fr));
       gap: 24px 14px;
     }
     ```
   - Update `.books-grid` to 1-column stacked layout:
     ```css
     .books-grid {
       grid-template-columns: minmax(0, 1fr);
       gap: 40px;
       margin-top: 40px;
     }
     ```
   - Update `.writing` to 1-column stacked layout under `767px` (previously stuck below `460px`):
     ```css
     .writing {
       grid-template-columns: minmax(0, 1fr);
       gap: 16px;
       padding: 24px 0;
     }
     .writing > figure {
       max-width: 100%;
       width: 100%;
     }
     .writing__aside {
       grid-column: 1;
       text-align: left;
       margin-top: 8px;
     }
     ```
4. **Ultrawide Capping (`@media (min-width: 1440px)`)**:
   - Ensure all `.page` and `.page--narrow` containers center cleanly with `--shell: min(100%, 1520px);` and `--shell-pad: clamp(16px, 4vw, 48px);`.
</action>
