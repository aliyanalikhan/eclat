# Phase 4 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope note:** Phase 4 introduces zero new pages and zero new visual design. Per GATE-05, the publicly-visible result (what a non-entitled user sees) must render exactly as it does today — `.paywall`, `.paywall__clip`, `.paywall__fade`, `.paywall__cta`, `.prose__blur`, `.pill`, and the `gate()` label pattern are reused verbatim. This contract exists solely to pin down the **new states** the phase's async, server-verified entitlement checks introduce: a loading/pending gap that did not exist before (the old `subscribed` flag was a synchronous local boolean), and a fail-closed error state for when the entitlement fetch itself fails. No optimistic or transitional UI may ever reveal gated content before a real server response confirms entitlement.

**shadcn gate — resolved without prompting:** `components.json` is absent and this project has no Tailwind/CSS-in-JS layer (confirmed: plain CSS in `src/styles/eclat.css`, per `CLAUDE.md`'s documented tech stack). Introducing a component library this phase would itself violate GATE-05 (no visual redesign) and the project's "reuse the existing design system as-is" constraint, so the shadcn init prompt was skipped as inapplicable rather than asked. `Tool: none` is correct for this phase, not a placeholder.

## Spacing Scale

This codebase does not use a strict 8-point grid (existing values include 11px, 13px, 18px, 22px, 26px, 44px, 56px, 96px, 110px, 130px etc., driven by editorial/visual judgment rather than a token scale). Phase 4 introduces **no new spacing values** — every new element (skeleton placeholders, error fine-print) must reuse the exact spacing of the sibling element it replaces or sits beside.

| Token | Value | Usage in this phase |
|-------|-------|-------|
| Edition gated-block skeleton | inherits `.paywall` (`padding-top: 56px`) and `.paywall__cta` (`margin-top: -10px`) exactly | Pending state occupies the identical box today's `.paywall` occupies — no new margin/padding introduced |
| Listing-label skeleton (Books/Writings/Archive) | inline, no block-level spacing change | Skeleton bar sits in the exact DOM position the label text (`gate()` output) sits in today — zero added margin |
| Error fine-print (Edition) | inherits `.fine` (`margin-top: 22px`) exactly | Reuses the same slot as the existing "Cancel anytime…" fine print — swapped copy/color only, not layout |
| Account.jsx loading gate | inherits existing `minHeight: 60vh` centered flex block (already used for the session-loading state) | Extended to also cover entitlement-loading — no new spacing |

Exceptions: none — this phase is spacing-neutral by design (GATE-05).

## Copywriting Contract

No new pages, no new destructive actions. The only new/changed copy this phase introduces:

| Element | Copy |
|---------|------|
| Primary CTA (Edition paywall, unchanged) | "Subscribe — $9/mo" — GATE-05: no copy change |
| Loading / pending state | **No visible copy.** Silent skeleton placeholders only (matches `Subscribe.jsx`'s existing price-skeleton precedent) — introducing "Loading…" text or a spinner would be a new visual pattern this editorial design language doesn't otherwise use, and isn't required since the gap is expected to be sub-second on a same-origin API call. |
| Empty state | Not applicable — no new empty-state surface is introduced this phase. Existing `.empty` copy ("No editions published that year.", "No invoices yet.") is untouched. |
| Error state (new) | Edition gated-block fetch failure only, replacing the existing "Cancel anytime. Covers and previews stay free." fine print **in this failure case only**: **"Couldn't confirm your subscription — reload to try again."** Rendered in `.fine` styling with `color: var(--bad)`, in the exact same DOM slot. The rest of the paywall (heading, CTA button, layout) stays identical to the ordinary not-entitled state — this is a fail-closed security posture, not a distinct error page. |
| Error state (listing labels) | None — Books/Writings/Archive `gate()`-label fetch failures fail closed **silently** to the existing not-entitled label text ("First spread free" / "Subscribers" / "Preview free"), with no separate error copy. This matches the already-established `useEntitlements()` contract (`src/lib/useEntitlements.js`: "callers must treat `error: true` as unknown, not confirmed free"). |
| Destructive confirmation | Not applicable — no destructive action is introduced or changed this phase. Note: the existing "Reset demo state" button and its fine print in `Account.jsx` (lines ~130–139, wired to `setSubscribed(false)`) must be **deleted outright** as part of GATE-02 (the flag it resets no longer exists) — this is a removal, not a redesign, and needs no replacement copy. Real cancellation UX is Phase 5's ACCT-02. |
