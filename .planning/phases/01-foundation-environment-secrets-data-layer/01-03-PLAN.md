Implement a manual recursive directory walk (do not rely on `readdir(dir, { recursive: true })`, since `package.json` has no `engines` field pinning a Node version — use `readdir(dir, { withFileTypes: true })` and recurse into subdirectories yourself for portability, matching PATTERNS.md's stated guidance).     After the full walk: if `leaked` is true, `process.exit(1)`; otherwise log `check-secrets: no leaked secrets found in dist/` and exit 0 (implicit).

This wires the scan into `npm run build` itself — run every time a build happens, not only inside the Vercel deploy pipeline, so a leak is caught locally the moment it occurs (D-14). This must run LAST — after `prerender.js`, since it scans the final `dist/` contents including prerendered HTML, not just the Vite JS bundle.
