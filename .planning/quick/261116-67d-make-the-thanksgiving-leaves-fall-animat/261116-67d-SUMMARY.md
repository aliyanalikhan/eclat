# Quick 261116-67d: Thanksgiving leaves fall Summary

The 6 static swaying hero leaves are now a CSS-only falling shower: 16 maple/oak leaves (8 on phones) drop from above the hero to below it while swaying and turning, behind the fan and the copy halo.

## What changed

- `src/routes/Home.jsx`: TG_LEAVES is the 16-row table from the plan (fields shape, line, hue, x, s, t, d, r, w, wide). Each leaf renders as `span.tg-leaf` (plus `tg-leaf--line` / `tg-leaf--wide`), with the custom properties and color set inline, wrapping the plain leaf svg. The sprite, the symbols, the aria-hidden wrapper and the THANKSGIVING gate are unchanged. No data-* attributes.
- `src/styles/eclat.css`, inside the labelled thanksgiving block only: the span is a full-height column with `tgLeafFall` (translateY -8% to 100%, opacity 0 to 0.6 to 0). The svg has `tgLeafSway` (translateX ±14px plus rotate from --r to --r+50deg). The `--line` styling is kept. Reduced motion sets `.tg-leaves { display: none }`. The bp:phone rule hides `.tg-leaf--wide` and sets width to `calc(var(--s) * 0.75)`. All six numbered rules, their phone overrides and the old sway are removed. Only transform and opacity animate.
- Line endings are still CRLF in both files.
