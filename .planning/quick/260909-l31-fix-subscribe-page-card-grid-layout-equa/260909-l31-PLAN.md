In `src/styles/eclat.css`, make these three edits (do not touch any other rule in the file):

1. `.plans` (~line 1330-1334): change `grid-template-columns: repeat(auto-fit, minmax(260px, 1fr));` to `grid-template-columns: repeat(2, 1fr);`. This is a fixed 2-column grid (not width-dependent auto-fit), so with exactly 4 `PRODUCTS` entries it always renders a stable 2x2 layout — structurally impossible for 3 cards to land in one row with a 4th alone in the next, at any viewport width above the new 720px collapse breakpoint added in edit 3. Keep `gap: 18px;` unchanged.

2. `.plan` (~line 1336-1345): add `display: flex;` and `flex-direction: column;` to the existing declaration block (alongside `font-family: inherit;` etc — do not remove or reorder any existing property). This makes `.plan__note` (added in edit below) able to bottom-anchor via `margin-top: auto`, since CSS Grid's default row-stretch already equalizes each `.plan`'s outer height per row and a flex column lets that extra height be distributed to a flex child instead of trailing as unused block-flow whitespace.

3. `.plan__note` (~line 1363-1367): change `margin-top: 10px;` to `margin-top: auto;` and add `padding-top: 18px;` (keep `font-size: 14px;` and `color: var(--muted);` unchanged). `margin-top: auto` on a flex child consumes all remaining free space above it, pushing it to the bottom of the (row-stretched) card; `padding-top: 18px` guarantees the same minimum gap above the button that the removed inline style previously provided, even on a card that isn't stretched taller than its own content (e.g. if only one card renders in a row at some future edge case).

4. In the existing `@media (max-width: 720px)` block (~line 1887-1965, the same block that already collapses `.field-pair` to `grid-template-columns: 1fr`), add a new `.plans { grid-template-columns: minmax(0, 1fr); }` rule, matching the exact collapse pattern already used for `.newest__grid`/`.ed-hero__grid` at the 900px breakpoint in this file. This makes the 2x2 grid collapse to a single column below 720px.

In `src/routes/Subscribe.jsx`, make this one edit:

5. Line 73: change `<span className="plan__note" style={{ display: 'block', marginTop: 18 }}>` to `<span className="plan__note">` — remove the inline `style` attribute entirely. This is required for edit 3's CSS `margin-top: auto` to take effect at all: inline styles always win over external class rules, so leaving `marginTop: 18` inline would silently block the bottom-anchoring fix from having any visible effect. `display: block` is not needed either — once `.plan` is `display: flex` (edit 2), `.plan__note` is a flex item and is laid out as a block-level box regardless of its own specified `display` value. Do not change any other prop, attribute, or line in `ProductTile` or `Subscribe`.

Do not touch `.plan__row`, `.plan__name`, `.plan__price`, `.plan__badge`, `.plan__interval`, `.plan__skeleton`, or any rule/route/component outside these five edits.
