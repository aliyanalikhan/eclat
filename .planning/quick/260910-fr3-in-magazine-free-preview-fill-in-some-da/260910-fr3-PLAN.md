<objective>
On a single edition page (`/editions/:no`), the "Inside this edition" / "Free preview" strip currently renders `samples` — a flat, edition-agnostic array in `src/data/content.js` whose captions ("Spread 02–03 · Orchard Road", "Page 07 · Portrait", etc.) and image paths (`/assets/images/samples/no-48/...`, a "no-48" edition that doesn't exist — the site only has editions 1 and 2) are generic placeholder content unrelated to either real edition. It renders byte-for-byte identical on `/editions/1` and `/editions/2`.

`src/data/content.js` already has real, edition-specific content for this exact purpose: the `articles` array, where each entry carries `editionNo`, `title`, `kicker`, `dek`, `alt`, `tint`, `img`, `slug` — already consumed correctly by `Home.jsx`'s "Featured articles" section. This plan swaps the strip's data source from the disconnected `samples` array to `articles` filtered by the viewed edition's `no`, so the free preview genuinely reflects the specific magazine being viewed, and removes the now-dead `samples` export.

Purpose: Replace placeholder/generic preview content with real per-edition data already present in the content model — a content-wiring fix only, no new fields, no auth/entitlement/paywall changes.
Output: `src/routes/Edition.jsx`'s preview strip renders edition-scoped `articles`; `src/data/content.js`'s unused `samples` export is deleted.
</objective>
