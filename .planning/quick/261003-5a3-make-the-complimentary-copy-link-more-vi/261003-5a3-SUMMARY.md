# Quick 261003-5a3 Summary

Both "complimentary copy" links on the Home page now loop a tasteful glow/flash animation at rest instead of
relying on hover alone to be noticed.

**What was done:**
- `src/styles/eclat.css` only — no JSX changes (both target classNames already existed in `src/routes/Home.jsx`).
- Hero `.hero__btn-complimentary`: added `animation: heroComplimentaryGlow 2.4s ease-in-out infinite;` and a new
  `@keyframes heroComplimentaryGlow` that pulses an accent-colored `box-shadow` ring and nudges the border toward
  `--accent` every 2.4s. Hover gets `animation-play-state: paused;` so the existing solid-accent hover treatment
  doesn't fight the glow.
- Closing CTA `.cta__complimentary` (the bar wrapper): given `padding: 10px 14px`, `border-radius: 14px`, and
  `animation: ctaBarFlash 2.6s ease-in-out infinite;` so the "whole bar" actually reads as a flashing panel instead
  of an invisible 0-height div. A new `.cta__complimentary:hover { animation-play-state: paused; }` rule pauses the
  bar flash whenever the pointer is over the link (hovering the child link also triggers `:hover` on the parent).
- `.cta__complimentary-link`: added `animation: ctaLinkGlow 2.6s ease-in-out infinite;` (independent keyframes from
  the bar, pulsing the link's own border/box-shadow toward `--accent-lit`) with its own `animation-play-state: paused;`
  on hover.
- New `@media (prefers-reduced-motion: reduce)` block disabling all three animations via `animation: none !important`
  on `.hero__btn-complimentary, .cta__complimentary, .cta__complimentary-link`, matching the two existing
  reduced-motion blocks already in the file.
- All new glow colors use the codebase's established `color-mix(in srgb, var(--accent[-lit]) N%, transparent)`
  pattern rather than inventing a separate `rgba()` approximation of the `oklch()` theme variables.

**Verification results:**

- `grep -c "animation:" src/styles/eclat.css` confirms the three new declarations (`heroComplimentaryGlow`,
  `ctaBarFlash`, `ctaLinkGlow`) are present, plus the new `@media (prefers-reduced-motion: reduce)` block (3rd such

- No other CSS rules were touched; `src/routes/Home.jsx` was not modified.
